Cache / render cost benchmark (T20-mini)

Equal operation rate (10 ops/s), fixed 400 operations, samples spread over the route; idle baseline subtracted. Lower is better.

  • maptiles — the map library's tile cache (the hidden ambient cache). render = cache emptied, tiles fetched/downloaded while benchmarking; pre-cache = tiles already downloaded and stored.
  • turnpreview — the small map picture shown at a turn. render = the picture is generated now, on the spot; pre-cache = the picture was generated earlier (the app's “Pre-cache” action) and is only decoded and shown now.
